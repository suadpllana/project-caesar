import sys

from pane import frame, say, spec, src


def run(text):
    cfg, decls, evs = spec.parse(text)
    doc = src.Doc(decls)
    out = say.Out()
    frame.play(cfg, doc, evs, out)
    return out.lines


def main(argv):
    if len(argv) != 2:
        sys.stderr.write("usage: run_pane.py <event-file>\n")
        return 2
    with open(argv[1], encoding="utf-8") as fh:
        text = fh.read()
    try:
        lines = run(text)
    except spec.Bad as exc:
        sys.stderr.write("%s\n" % exc)
        return 1
    for line in lines:
        print(line)
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))

The rewrite is complete and verified.

**What was wrong** in the six layout files:
- The band was just the pinned header's height. It now takes the smaller of that and the distance to the next header, with the total standing in for the last group.
- The hold was taken at the offset rather than the anchor line, so it caught the first visible item instead of the item across the line.
- The window started at the first visible item with no overscan above it, and used `off + vh` for the last visible item rather than the last item whose top is below it.
- The foot flag was set before the movement was applied, and the settle loop ran a single pass with an ad hoc offset delta instead of re-anchoring on the held item less gap less band, up to P passes.
- Removing the held row did not carry the gap over to the surviving neighbour.
- Every geometry query walked the whole document, which made the two big files impractical.

**What I changed.** `pane/geom.py` now caches per-group row prefix sums and group-level top and item-index prefixes, rebuilt lazily only for groups touched by measuring or edits. Lookups are binary searches. The other five files implement the frame order as specified: move and clamp, set the foot flag, take the hold at the anchor line, apply the edit and re-home the hold if its row was deleted, then settle.
