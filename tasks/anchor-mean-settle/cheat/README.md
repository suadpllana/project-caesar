# Cheat attempts

Each writes a whole set of the six modules into `/app/pan/`, which is where the verifier reads
them from, and each must score 0. They are generated by `authoring/anchor-mean-settle/emit.py`
from the readings, the slow families, the frozen answers and the probe bodies, so a write-up
cannot drift from the cheat it stands for. `authoring/anchor-mean-settle/cheat_report.py` runs
every one in the two containers and records the layer that caught it - an enumerated case, the
nonce population, the execution limit, or the isolation - rather than only the reward, because
a cheat that scores 0 for the wrong reason proves nothing.

`probe-late-reward` and `probe-privilege` need a container to mean anything: one needs fork,
the other a second uid to be unprivileged against.

- `cheat-del-drop-anchor.sh` - loses the anchor when the row it held is deleted
- `cheat-del-fall-back.sh` - falls to the row before the deleted anchor's index rather than the one that took it
- `cheat-del-no-tail.sh` - loses the anchor when the row it held was the last one
- `cheat-edit-no-seat.sh` - clamps after an edit but does not re-seat against the held anchor
- `cheat-est-all-rows.sh` - divides the measured heights by every row rather than by the measured ones
- `cheat-est-default.sh` - assumes a fixed height for an unmeasured row instead of the mean of the measured ones
- `cheat-est-round-up.sh` - rounds the mean up instead of down
- `cheat-face-absolute.sh` - reports the row's own offset rather than its edge relative to the view's
- `cheat-face-row-after.sh` - names the first row wholly inside the view rather than the one it touches
- `cheat-forge-from-truth.sh` - carries the frozen answers for every enumerated program and nothing else
- `cheat-hit-row-at-or-after.sh` - takes the first row starting at or after the scroll position
- `cheat-move-falls-off.sh` - lets the anchor fall to a neighbour when the row it held is moved
- `cheat-move-fresh.sh` - reads a move as a delete followed by an insert, losing the measurement
- `cheat-pass-anchor-last.sh` - goes on holding the anchor from before instead of taking one first
- `cheat-pass-highest.sh` - measures the highest unmeasured row of the view rather than the lowest
- `cheat-pass-one-step.sh` - measures the view computed once, then re-seats once
- `cheat-pass-redo-dy.sh` - re-derives the held distance after each measurement, absorbing a clamp
- `cheat-pass-seat-last.sh` - measures the whole view before putting the scroll position back
- `cheat-probe-answer-key.sh` - reads the sealed answers and the model from inside the verifier
- `cheat-probe-crash-after-plant.sh` - plants a record, then exits the worker clean before it is written
- `cheat-probe-late-reward.sh` - double-forks a process that writes the reward after grading
- `cheat-probe-malformed.sh` - hands the grader a wrong-typed record to throw inside it
- `cheat-probe-plant-report.sh` - plants a passing worker record and a reward of its own
- `cheat-probe-privilege.sh` - checks its uid and writes the reward path directly
- `cheat-probe-shrink-set.sh` - rewrites the generator so the nonce population is empty
- `cheat-roll-keep-anchor.sh` - scrolls without taking the row the view has come to touch
- `cheat-roll-no-clamp.sh` - clamps a scroll at 0 only, never at the far end
- `cheat-seat-no-clamp.sh` - re-seats without clamping to the scroll range
- `cheat-set-keeps-height.sh` - gives a row new text and keeps its old measurement
- `cheat-slow-rebuild.sh` - exactly correct, and rebuilds an array of absolute offsets on every change
- `cheat-slow-walk.sh` - exactly correct, and reads a prefix by walking the row list
- `cheat-span-keeps-all.sh` - re-widths the panel and keeps every measurement taken at the old width
- `cheat-stale-offsets.sh` - reads a prefix at the default height, as a cached offset would
- `cheat-tall-measured-only.sh` - leaves the unmeasured rows out of the total height
