# Cheats

Three families. Every one of them scores 0, and `authoring/cheat_report.py` prints
which layer caught each so that a probe rejected for the wrong reason cannot pass
as a probe that worked.

**Single-mistake readings.** The whole reference with exactly one decision made the
way a solver who missed one piece would make it, generated by `authoring/emit.py`
from an anchored block of the reference source. They are generated rather than
written by hand because a hand-written variant that forgets one of the other
corrected files silently tests the shipped bug instead of the mistake it was aimed
at. The most valuable of them get every fence right and differ on one seal.

**Reward probes.** Built on the SHIPPED policy, never on the reference: a probe
built on the reference does the real work and would score 1 for honest reasons.
They go after the reward channel, the report file, the verifier directory, the
executed tree and the emitter.

**Attestation probes.** The two exceptions, built on the REFERENCE on purpose.
Each is correct on every plan and interferes with exactly one attestation, which
is the only way to learn whether that layer fires at all: a probe that is wrong on
the answers fails for a reason unrelated to the layer it was aimed at.

**The answer key.** `cheat-answer-key.sh` carries `tests/gt.json`'s own bytes and
is right on all thirty-one enumerated plans. It scores 0, because the three hundred
plans behind them are built from a nonce drawn after the submission was written.
