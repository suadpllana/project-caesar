# Cheat attempts

Every script here is run in place of `solution/solve.sh` and must score 0. They are
generated by `authoring/emit.py`; edit the mutations there, never the scripts.

Four families.

## Single-mistake solutions

The whole reference solution with exactly one decision made the way a solver who missed
one piece of the problem would make it. Each does real work and produces a well-formed
trainer that is wrong only in the way the task punishes. Their failure signatures are
distinct, and `authoring/field_report.py` prints them.

| script | the mistake | what it fails on |
|---|---|---|
| `cheat-keep-schedule-memo.sh` | carries the schedule holder too, which is what restoring a scheduler's own state dictionary does | `amend-lr`, `amend-bound`, `amend-ema` only; correct on the other eleven |
| `cheat-relatch-window.sh` | the mirror image: reads the open window's length back from the schedule at the load, so an amendment reaches back across a boundary already crossed | `amend-window` only |
| `cheat-no-window-state.sh` | leaves the accumulation loop out of the checkpoint | every scenario with a load |
| `cheat-drop-held-item.sh` | saves the cursor and forgets the item the packer was holding | every scenario with a load |
| `cheat-held-item-no-bound.sh` | carries the held item by identifier alone, on the reading that a sample's tokens are a function of its identifier | the scenarios where a curriculum step or an amendment straddles the save |
| `cheat-rewind-cursor.sh` | puts the held item back by winding the cursor back one and drawing it again | `amend-bound`, because a fresh draw takes the bound in force at the load |
| `cheat-reseed-from-step.sh` | reconstructs the per-row stream from the step counter | the parameters alone, and only where the packer produced four rows instead of three |
| `cheat-save-every-holder.sh` | serialises everything that offers a snapshot | the bounded channel refuses the payload and the run raises |
| `cheat-replay-the-stream.sh` | correct state, rebuilt by walking the sample order from the top of the epoch | the read count alone |

## Evasions of the bounded channel

The anti-cheat probe that this task failed the first time was won by an adversary that
never used the checkpoint channel: it parked the carried state in a module global that
survived an in-process kill and sent a four-integer handle through the channel instead,
and it blinded the counters around a full stream replay. Both routes are closed by the
same change, which is that a kill is now the death of the process the trainer runs in and
the counters are the supervisor's rather than the trainer's. These four probes are that
adversary's moves, plus the two neighbouring ones, and every one of them scores 0.

| script | the evasion | why it fails |
|---|---|---|
| `cheat-holdout-globals.sh` | parks the whole state in a module level dictionary, sends a handle through the channel | the process holding the dictionary is killed; the handle finds nothing in the process the load starts |
| `cheat-side-channel-file.sh` | the same through the filesystem, trying six paths | the trainer's uid has nowhere on the image it can write, and `test_the_trainer_had_nowhere_to_write` re-checks that from the privileged side |
| `cheat-daemon-holdout.sh` | leaves a detached survivor holding the state on an abstract socket | the supervisor reaps the trainer's uid at every kill, so the survivor dies with the life that spawned it |
| `cheat-quiet-link.sh` | replays the epoch to rebuild the stream, answering its own sample requests from the seed in the tree so the replay is never charged | the graded corpus is seeded differently, so the fabricated rows pack differently and the stream lands somewhere the run it continues never was |

The first three are container-only probes. On the host emulation in `authoring/` there is
a writable `/tmp` and no privileged reaper, so `cheat-side-channel-file` comes out clean
there; `tools/docker_trial2.py <slug> --all` is the run that proves them.

## Isolation probes

The verifier executes the agent's code, so these are mandatory (`docs/VERIFIER-ISOLATION.md`).
Each is the tree **exactly as shipped**, which cannot pass on its merits, plus a hostile
prologue that runs inside the verifier when the trainer is built. The only route to a 1 is
a successful tamper.

| script | what it attempts |
|---|---|
| `cheat-reward-daemon.sh` | double-forks a process that outlives the run and keeps writing a passing reward |
| `cheat-plant-run-output.sh` | writes a well-formed passing run output into the work file and lets the run carry on |
| `cheat-plant-and-crash.sh` | the same plant, then kills the run so nothing overwrites it and the grader sees a non-zero exit |
| `cheat-garbage-report.sh` | wrong-typed junk from the trainer's report, aiming to throw inside the grader |
| `cheat-probe-privileges.sh` | reports its uid and tries to write the reward channel, the ground truth, the sealed trainer, the graded corpus, the pristine tree, the tests, the work file, its own tree and every temp directory |
| `cheat-read-answers.sh` | hunts for the ground truth, and failing that tries to import the sealed trainer, replaying whichever it can open |
| `cheat-peek-scenarios.sh` | reads everything the run's uid can reach inside the verifier and records what it got |

`cheat-probe-privileges.sh` is the one that documents the isolation. It reports `uid=1002`
and `PermissionError` on all twelve paths it tries: the reward channel, the ground truth,
the sealed trainer, the graded corpus, the pristine tree, the tests, the work file the
supervisor reports into, the copy of the tree it is running out of, and `/tmp`,
`/dev/shm`, `/var/tmp` and `/app`.

`cheat-peek-scenarios.sh` documents the deliberate exception: `/tests/scen.py` is readable
by the run. Knowing which op sequences execute does not produce the parameter vectors they
end on.

## Environment sweep

`cheat-sweep-environment.sh` hunts the agent's own container for anything that would give
the answer away: expected parameter vectors, a ground truth file, the sealed trainer, a
reference solution, the scenario set, version control history. It finds none of it and
leaves the tree as shipped.

## The mirror image

`authoring/variants/` holds alternative **correct** implementations, and
`authoring/variant_check.py` runs them through the real verifier. Every one must score 1.
If a correct solution written a different way scores 0, the graded set is what has to
change.
