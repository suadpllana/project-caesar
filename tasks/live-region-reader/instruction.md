`/app` is the speech side of a headless screen reader we run in UI tests: it replays the mutations of a page and prints what someone using assistive technology would hear. `python3 /app/run_sr.py <script>` reads one page script and prints the log. A script starts with `page T`, the last tick, and then `@t` lines open the ticks in rising order, `@0` being the load. Inside a tick, `add <id> <parent> <pos> el <tag>` and `add <id> <parent> <pos> tx <words>` insert a new element or text node as child `<pos>` of `<parent>`, counting from 0, or last for `end`. `move <id> <parent> <pos>` moves a node together with everything under it, `<pos>` counted once the node has been taken out; `drop <id>` removes one for good; `text <id> <words>` replaces the words of a text node; `set <id> <name> <value>` and `unset <id> <name>` change an attribute of an element. Node 0 is the page itself. It never moves and is never dropped. It carries no attributes. Ids are never reused. Words are lowercase letters and digits separated by single spaces. The elements that carry `aria-live` are fixed during the load. On those elements it is always `polite`, `assertive` or `off`: a later tick may switch it between those three, but never sets it on another element or unsets it. `/app/pages` holds five scripts.

The reader has been wrong since it was written. On `/app/pages/tiny.txt` it prints two lines where it should print these three: `1 polite offline`, then `4 polite offline`, then `8 polite online`.

You may change `/app/sr/look.py`, `/app/sr/know.py`, `/app/sr/watch.py`, `/app/sr/unit.py`, `/app/sr/line.py` and `/app/sr/voice.py`, and nothing else. The rest of the tree is replaced by our own copy before a script is run. A file you add beside those six is not used. `run_sr.py` builds `Reader(page)` from `/app/sr/voice.py` and calls its `load()` once the load is applied. After all of each later tick's operations it calls `step(t, records)` with that tick's mutation records. It prints the lines `step` returns.

A node is exposed while it is on the page and no element at or above it carries `hidden`, with any value, or `aria-hidden="true"`; `aria-hidden="false"` exposes nothing that such an element hides. The region of a node is the nearest element at or above it that carries `aria-live`. `off` counts: an off region inside a polite one is a region of its own. Text with no region above it is never spoken. A region voices while it is exposed and polite or assertive.

For every region and every text node the reader believes that certain words are there, or that nothing is. At the end of the load it believes exactly what is exposed. It says nothing about the load. Each belief also remembers the parent the node had when those words were taken: at the load, when a difference was absorbed, or when the utterance that taught them started. Belief changes in only two ways: an utterance finishes and the reader believes what it carried, or a difference is absorbed.

At the end of every tick the reader compares, for each region and text node, the words the node has if it is exposed in that region now with what it will believe once the utterance it is playing has finished, which is what that utterance carries for the pair if it carries it and the belief otherwise. Nothing before and words now is an addition, words before and nothing now a removal, and different words a text change. Equal words are no difference, however the node moved inside its region. A difference whose region does not voice, or whose kind the region element's own `aria-relevant` does not name, is absorbed on the spot: the reader believes the current words, and the playing utterance stops carrying that pair. `aria-relevant` takes the tokens `additions`, `removals`, `text` and `all`, separated by spaces, and ignores any other token; missing, or with no token it knows, it means `additions text`. `aria-relevant` anywhere else means nothing.

Any other difference waits, and its age is the tick at whose end it was found. It keeps that age for as long as it lasts, whatever happens to its words. Once it is gone, a difference found later is a new one. A waiting difference is held while an element on its path carries `aria-busy="true"`. For an addition or a text change the path runs from the node's parent up to and including its region element. For a removal it runs from the remembered parent up to and including the region element when that parent is still exposed in the same region, and is the region element alone otherwise.

Whenever nothing is playing, the reader takes the oldest unheld waiting difference in an assertive region, or failing that the oldest in a polite region. On equal ages the lower text node id goes first, then the lower region element id. The start is the node's parent, or for a removal the remembered parent when it is still exposed in the same region; otherwise the removal has no start. From the start up to and including the region element, the first element whose `aria-atomic` is `true` or `false` decides: `true` makes that element the unit, and `false`, reaching the region element without either, or having no start means there is no unit. A unit is spoken as the words of every exposed text node inside it, in document order (depth first, an element before its children, children in order), one space between. The utterance carries every unheld waiting difference whose unit is that same element. Without a unit, an utterance speaks the node's words, or for a removal the word `removed` followed by the believed words, and carries that one difference. A carried difference no longer waits. If a unit has no exposed words, nothing is said and the utterance counts as finished at once: the reader believes what it carried and chooses again.

An utterance of w words started at tick t finishes at tick t + w. It is polite or assertive as its region was when it started. While a polite utterance is playing, an unheld waiting difference in an assertive region cuts it off. The cut utterance teaches nothing. Every pair it carried is compared again against belief, and a difference found there waits at the age it had when the utterance took it. Nothing cuts an assertive utterance.

A tick runs in this order: its operations, then the playing utterance finishing if its tick has come, then the comparison, then a cut, then choosing as often as nothing is playing. Ticks run from 1 to T whether or not a script names them. The log has `<t> polite <words>` or `<t> assertive <words>` for each utterance started and `<t> cut` for each cut, in the order they happen, and nothing else.
