# Cheats

53 attempts, every one of which must score 0. They are generated by
`authoring/owed-check-rewind/emit.py` from the reference. Do not edit them by hand: a hand-edited
cheat drifts away from the reference it was derived from and stops testing anything.

Thirty-nine are wrong readings: the reference with one graded decision taken the other way, such
as `cheat-walk-breadth`, `cheat-recompute-ledger`, `cheat-place-not-restored` or
`cheat-list-moved`. They test the graded set. Each is caught by the hand program named for it,
which `cheat_report.py` asserts, and most also move a share of the generated population.

`cheat-slow-copy`, `cheat-slow-scan` and `cheat-slow-ledger` print exactly the right lines. They
copy the rows and the ledger at every savepoint, scan a table for the rows holding a key, or copy
the ledger alone at every savepoint, and only the 60 second clock separates them from a solution.
`cheat-const-ok` prints `ok` for every statement.

`cheat-forge-hand` is handed `tests/seal/gt.json` outright and replays the frozen answer for every
hand program it recognises. It passes all fifty, and it scores 0 because the generated programs
are drawn inside the verifier from a seed made after the agent has finished.

The nine `cheat-probe-*` scripts sit on the reference with one small defect, a min check that
fails on null, so they can score 1 only by beating the isolation. `answer-key` reads the sealed
model and the frozen answers. `privilege` checks its uid and writes the reward. `late-reward`
double-forks a writer that outlives stage one. `plant-record` plants a record for the worker to
overwrite, and `crash-worker` plants one and exits before it can be overwritten. `malformed`
spoils the record on exit. `shrink-set` rewrites the population size and the generator.
`disarm-grader` rewrites the grading file. `uncollected-file` moves the executor into a file
beside the six, which the verifier never collects.
