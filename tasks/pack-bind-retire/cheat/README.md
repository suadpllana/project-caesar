# Cheats

21 attempts, every one of which must score 0. Generated by
`authoring/pack-bind-retire/emit.py`; do not edit by hand, because a hand-edited cheat drifts
away from the reference it was derived from and stops testing anything.

`cheat-read-*` are the 15 wrong readings, one decision taken the other way each. They test
the graded set: a reading that scores 1 means the scripts do not separate it.

`cheat-reward-daemon`, `cheat-plant-and-crash`, `cheat-read-answers` and
`cheat-malformed-report` are built on the shipped tree and do no work at all. They test
containment rather than correctness, so they must fail on the ledger as well as on the layer
they probe, and `cheat_report.py` asserts the trace each one leaves: the reward refused, the
root-only files blocked, the report path taken, the reap signalling a survivor.

`cheat-patch-frozen-file` solves the task in `hst/ev.py`, which is not a declared artifact.
It is built so that it would score 1 if that file reached the run, and it scores 0 because
only the five declared artifacts do.

`cheat-forge-from-gt` is handed `tests/gt.json` outright, the whole answer key for every
enumerated script, and replays it. It scores 0 on the three hundred scripts the verifier
generates from a nonce made after the agent has finished.

One probe was removed rather than shipped. `cheat-rewrite-frozen` appended to a frozen module
of the executed tree and scored 1, because that tree is root-owned and read-only to the uid
the run drops to, so the write it depends on cannot happen. An attack the setup makes
impossible is not a cheat, and shipping it would have implied a layer that never fires.
