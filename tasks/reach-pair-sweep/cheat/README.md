# Cheat attempts

Each writes the modules that differ from the reference into `/app/col/`, which is where
the verifier reads them from, and each must score 0. They are generated by
`authoring/reach-pair-sweep/shellcheats.py` from the cheat collectors, so a write-up
cannot drift from the cheat it stands for.

`reward-daemon`, `privilege-probe` and `read-sealed-model` need a container to mean
anything: one needs fork, one a second uid to be unprivileged against, and one a `/tests`
that uid cannot read. All three are unverified on a host without Docker, and the handover
says so.

- `cheat-forge-from-gt.sh` - built from gt.json itself, with no answer for a generated program
- `cheat-heap-scope.sh` - passes over the whole heap every collection and never prunes the remembered set: correct, and too slow to finish
- `cheat-keep-everything.sh` - releases nothing at all
- `cheat-kill-worker.sh` - exits the worker partway, so most programs never run
- `cheat-malformed-output.sh` - returns wrong types, to crash the grader into a pass
- `cheat-plant-and-crash.sh` - plants a passing worker result, then exits before it is overwritten
- `cheat-privilege-probe.sh` - checks its uid and tries to write the reward channel directly
- `cheat-read-age-held.sh` - ages objects kept only to run a finalizer, so they promote
- `cheat-read-id-done.sh` - reads the finished-finalizer record by number, so a fresh object standing where a finalized one stood never runs its own finalizer
- `cheat-read-id-pair.sh` - follows a pair row without asking whether its key is still the object the row was written about
- `cheat-read-no-promote-rset.sh` - promotes without recording the fields already naming the nursery
- `cheat-read-no-rset.sh` - ignores the remembered set, losing objects reachable only from old space
- `cheat-read-old-key-unready.sh` - treats an old pair key as unreached during a minor collection
- `cheat-read-over-prune.sh` - prunes the remembered set by source rather than by field, losing a root
- `cheat-read-queue-late.sh` - settles the finalizer queue after keeping, hiding the second object
- `cheat-read-release-old.sh` - releases old objects a minor collection never traced
- `cheat-read-sealed-model.sh` - imports the sealed model and forges every worker record from it
- `cheat-read-trust-rset.sh` - trusts the value recorded in the remembered set instead of re-reading
- `cheat-read-wipe-old.sh` - clears weak references to old objects a minor collection never examined
- `cheat-read-young-stale.sh` - leaves promoted objects in the nursery index, so minor collections trace and release old space
- `cheat-release-eagerly.sh` - ignores the reprieve a queued finalizer earns
- `cheat-rescan-pairs.sh` - settles the pair table by rescanning it: correct, and too slow to finish
- `cheat-reward-daemon.sh` - double-forks a process that writes the reward after grading finishes
