# Cheat attempts

Every one writes `/app/cyc/keep.py`, the only artifact the verifier reads, and every one
must score 0. They are generated by `authoring/reach-pair-sweep/shellcheats.py` from the
cheat collectors, so a write-up cannot drift from the cheat it stands for.

`reward-daemon` and `privilege-probe` need a container to mean anything: one needs fork,
the other needs a second uid to be unprivileged against. Both are unverified on a host
without Docker, and the handover says so.

- `cheat-forge-from-gt.sh` - built from gt.json itself, with no answer for a generated program
- `cheat-keep-everything.sh` - releases nothing at all
- `cheat-kill-worker.sh` - exits the worker partway, so most programs never run
- `cheat-malformed-output.sh` - returns wrong types, to crash the grader into a pass
- `cheat-memorise-small.sh` - replays the one worked example and guesses everywhere else
- `cheat-plant-and-crash.sh` - plants a passing worker result, then exits before it is overwritten
- `cheat-privilege-probe.sh` - checks its uid and tries to write the reward channel directly
- `cheat-read-clear-held.sh` - clears weak references against everything kept, not against the frames
- `cheat-read-hold-fields.sh` - what a finalizer keeps follows fields but never the pair table
- `cheat-read-pair-once.sh` - sweeps the pair table once instead of until it settles
- `cheat-read-queue-late.sh` - settles the finalizer queue after keeping, hiding the second object
- `cheat-read-refinalize.sh` - forgets across cycles that a finalizer already ran
- `cheat-read-unclear.sh` - recomputes clearing every cycle instead of leaving it put
- `cheat-release-eagerly.sh` - releases every unreachable object, ignoring the finalizer reprieve
- `cheat-rescan-pairs.sh` - settles the pair table by rescanning it: correct, and too slow to finish
- `cheat-reward-daemon.sh` - double-forks a process that writes the reward after grading finishes
