# Cheat attempts

Every script here must score 0. They are generated by `authoring/make_cheats.py`; edit that
file rather than these, so the mutations stay anchored to the current reference solver.

Run them all with:

```
python3 tools/run_local.py --all
```

Eight of them are the reference solver with exactly one step done the way a solver that
missed the corresponding piece of chemistry would do it. These are the interesting ones:
they do real work, produce a well-formed and internally consistent network, and are wrong
only in the specific way the task is designed to punish.

| Script | What it does wrong | What catches it |
|---|---|---|
| `cheat-no-temperature-correction.sh` | Uses the tabulated 298.15 K free energies at the reactor temperature | Two equilibrium flags, several `delta_r_g` values, and one exclusion reason |
| `cheat-reference-temperature.sh` | Evaluates everything at 298.15 K, concentrations included | Same, plus a tenth reaction joins the network because a cleavage drifts into the equilibrium band |
| `cheat-trust-declared-formulas.sh` | Balances from the typed formula strings instead of the structures | Three reactions that are really running stop balancing and vanish from the network |
| `cheat-ignore-charge-balance.sh` | Balances elements but not total charge | Candidates acquire spurious balances, so membership and several reasons go wrong |
| `cheat-written-directions.sh` | Reports every reaction in the direction the candidate file writes it | The reaction that runs backwards and the one with zero net flow |
| `cheat-flux-only-membership.sh` | Keeps a reaction only if it carries net flux | Drops the equilibrated pair that carries none but is still part of the network |
| `cheat-signal-count-only.sh` | Assigns the C5H7O4- isomer on carbon signal count alone | Two isomers share the count; the attached-proton pattern is what separates them |
| `cheat-first-valid-atom-map.sh` | Takes the first element-preserving atom map rather than the one conserving most bonding | Atom maps, and every tracer prediction that depends on them |
| `cheat-forward-label-only.sh` | Propagates tracer label only along written directions | Label predictions for the runs that reach species through the reversed step |

The remaining three do no chemistry at all and exist to prove the verifier is not satisfied
by shape alone: `cheat-empty-network.sh` writes a schema-shaped but empty file,
`cheat-every-candidate.sh` declares every candidate active with zero fluxes and empty atom
maps, and `cheat-search-environment-for-answer.sh` sweeps the agent image for ground-truth
material before writing a stub. The sweep finds nothing; the only executable shipped to the
agent is a schema checker that never mentions the chemistry.

One earlier cheat did score 1. In the first build the true intermediate was `P1`, and
`cheat-signal-count-only.sh` picked the first hit alphabetically, which happened to be the
right answer. The fix was to the data, not the test: the true isomer is now `P2`, so both
"first in the file" and "first alphabetically" land on the wrong one and the attached-proton
evidence has to be used. See STATE.md.
