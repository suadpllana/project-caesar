# Cheat attempts

Each writes the accounting files the verifier reads from `/app/bil/`, and each
must score 0. They are generated by `authoring/space-charge-shift/emit.py` from
the reference solution, so a write-up cannot drift from the cheat it stands for.

`reward-daemon` and `privilege-probe` need a container to mean anything: one
needs fork, the other a second uid to be unprivileged against.

- `cheat-answer-key.sh` - carries the frozen hand-case answers and guesses the rest
- `cheat-any-over.sh` - refuses whenever a space ends over its limit, even when it is coming down
- `cheat-arrival-order.sh` - charges the link the accounting saw first, not the oldest
- `cheat-big-shortcut.sh` - stops keeping the accounting once the store is large, to beat the clock
- `cheat-claim-charged.sh` - keeps charging content whose last link is gone while a claim is open
- `cheat-key-hunt.sh` - looks for the answer key in the container and guesses when it is absent
- `cheat-kill-worker.sh` - exits the worker partway, so most scripts never run
- `cheat-malformed-output.sh` - returns wrong types, to crash the grader into a pass
- `cheat-move-blind.sh` - leaves the charge where it was when a folder moves to another space
- `cheat-never-refuse.sh` - lets every operation through and never reads the limits
- `cheat-newest-link.sh` - charges the newest link instead of the oldest
- `cheat-per-asset.sh` - charges every asset for its own content, so a shared one is paid for twice
- `cheat-plant-and-crash.sh` - plants a passing worker result, then exits before it is overwritten
- `cheat-privilege-probe.sh` - reads for the answers, then tries to write the reward channel
- `cheat-recompute.sh` - correct, and reads every content to answer a space: too slow to finish
- `cheat-retag-new-only.sh` - settles the content an asset joins and forgets the one it left
- `cheat-reward-daemon.sh` - double-forks a process that writes the reward after grading finishes
- `cheat-step-limit.sh` - tests the limit after each change instead of on the state produced
- `cheat-subtree-walk.sh` - correct, and walks a moved folder link by link: too slow to finish
