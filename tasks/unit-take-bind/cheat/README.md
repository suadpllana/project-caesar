# Cheat attempts

Each writes the four files the verifier reads out of `/app/res/`, and each must
score 0. The wrong-reading scripts are generated by
`authoring/unit-take-bind/shellcheats.py` from the readings measured in
`authoring/unit-take-bind/readings.py`, so a write-up cannot drift from the
engine it stands for; the probes below them are written by hand.

`reward-daemon` and `privilege-probe` need a second uid to mean anything, and
`read-the-answers` needs `/tests` to be root-only. All three were run against
the shipped `tests/test.sh` at its own absolute paths, with the same sandbox
uid the verifier image creates.

- `cheat-read-als-costs-one.sh` - prices `als` a step out rather than where the unit declared it
- `cheat-read-clash-by-unit-only.sh` - compares only the unit of two candidates, so an item and a unit of the same name agree
- `cheat-read-clash-carries.sh` - carries a contested name onward as though it were bound
- `cheat-read-clash-on-any-two.sh` - contests whenever two candidates arrive, even from one origin
- `cheat-read-clash-retry.sh` - settles a contested name again from a later, single candidate
- `cheat-read-cost-adds-source.sh` - adds the two ranks a pull is priced from instead of taking the larger
- `cheat-read-cost-drops-source.sh` - prices a pull by the name's rank in the source alone, ignoring the rank of the reading that chose that source
- `cheat-read-first-wins.sh` - takes the first of the cheapest candidates rather than contesting them
- `cheat-read-hide-drops-local.sh` - reads `hide` as taking the name out of its own unit as well
- `cheat-read-in-place-sweep.sh` - relaxes until nothing moves, updating in place, so a binding carried onward before its second route arrives is never withdrawn
- `cheat-read-narrow-blocks-shut.sh` - stops a pull that names a shut name from reaching it
- `cheat-read-narrow-takes-hidden.sh` - lets a pull that names a hidden name reach it
- `cheat-read-src-free-rank.sh` - reads a locally bound source at no cost, whatever that binding cost
- `cheat-read-src-global-only.sh` - reads a pull's source name only as the program's unit of that name
- `cheat-read-src-local-only.sh` - lets a local binding of the source name shut out the program's own unit of that name
- `cheat-read-wide-takes-shut.sh` - lets a wide pull take a name that is shut
- `cheat-forge-answer-key.sh` - carries tests/gt.json verbatim and answers from it, with nothing for a generated program
- `cheat-kill-the-worker.sh` - exits the worker part way, so most programs never run
- `cheat-malformed-record.sh` - returns wrong types, to throw inside the grader rather than fail in it
- `cheat-plant-and-exit.sh` - plants a full worker record and exits the worker cleanly before the programs are run
- `cheat-privilege-probe.sh` - checks its uid and writes the reward channel directly
- `cheat-read-the-answers.sh` - reads the sealed model and the frozen answers out of the verifier at run time
- `cheat-reward-daemon.sh` - double-forks a process that writes the reward after grading has finished
- `cheat-swap-the-record.sh` - rewrites the worker's record from a background process after the worker has exited
- `cheat-sweep-the-work-dir.sh` - scans the work directory for anything the grader will compare against
